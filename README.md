# 有邻：部署与体验说明

本包为项目源码，包含校园问答、失物登记与互助、校园论坛、处理过程展示和相关测试。它不包含发送者的数据库、聊天记录、上传文件、API 密钥或 node_modules。首次启动会创建独立的空数据库及项目自带的演示数据。

## 一、运行环境

- Windows、macOS 或 Linux；需要可写的本地磁盘。
- Node.js 22（本项目在 Node.js 22.14.0 的现有依赖环境中启动过服务进程）。
- pnpm 12.17.0。安装依赖需要能够访问包仓库。
- 可选：DeepSeek API 密钥。没有密钥也能体验规则驱动的校园服务；一般聊天使用本地占位逻辑，并非离线大模型。

## 二、首次运行

1. 解压并进入 `YouLin` 文件夹，在该目录打开 PowerShell、终端或命令提示符。
2. 安装指定的 pnpm 版本；如果已经安装 12.17.0，可跳过：

   ```bash
   corepack enable
   corepack prepare pnpm@12.17.0 --activate
   pnpm --version
   ```

   若系统没有 Corepack，请按 Node.js / pnpm 官方说明先安装 Corepack，或自行安装 pnpm 12.17.0。
3. 安装项目依赖：

   ```bash
   pnpm install --frozen-lockfile
   ```

4. 将 `.env.example` 复制为 `.env.local`。例如 Windows PowerShell：

   ```powershell
   Copy-Item .env.example .env.local
   node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
   ```

   将终端生成的随机值填入 `.env.local` 的 `AUTH_SECRET=` 后面并保存。每个部署应使用自己的随机值，且不要把 `.env.local` 或真实密钥分享出去。
5. 如要启用 DeepSeek 一般对话，在 `.env.local` 中填写自己的 `DEEPSEEK_API_KEY`。模型名可按服务商当前提供的名称设置，默认 `deepseek-flash`。确认配置后重启服务。调用 API 可能产生费用；对话会发送给所配置的模型服务商。供应商接口说明： https://api-docs.deepseek.com/quick_start/ 。
6. 本机体验启动：

   ```bash
   pnpm exec next dev --hostname 127.0.0.1 --port 3000
   ```

   浏览器打开 <http://127.0.0.1:3000>，进入注册页面自行创建账号并登录。交付副本已移除原有固定演示账号，不会自动创建 `123456` 账号。按 Ctrl+C 结束服务。

## 三、体验主要流程

1. 用账号 A 登录，在对话中输入“我在图书馆捡到一张校园卡”。
2. 检查登记内容后回复“确认”；再说“发布这条失物到论坛”，检查预览后回复“确认发布”。
3. 从消息里的链接进入帖子。可用另一浏览器或无痕窗口注册账号 B，登记同类别的失物，从相关帖子进入详情并通过站内消息联系。
4. 账号 A 返回帖子详情刷新消息；完成线下交接后，在对话中输入“已归还”，核对记录后确认。关联帖子会标记为发布者反馈已解决。

匹配结果仅表示可能相关；系统不核验身份或证明线下交接。自动隐私识别不完整，请自行检查公开内容，不要发布证件号码、验证码、学号或不愿公开的联系方式。站内消息没有自动通知，需手动刷新。

## 四、数据与配置

- 没有 `POSTGRES_URL` 时，使用工作目录下的 `data/campus-db`。这个本地数据库仅适合单机、单进程体验；保留该目录才能保留账号、聊天、失物、帖子与联系消息。备份时先正常停止服务。不要在同一数据目录同时启动多个进程。
- 图片上传到 `public/uploads`；迁移机器时如需保留上传文件，应和数据库一起备份。
- 报修工单目前保存在服务器进程内存里，重启会丢失，不会提交到学校报修系统。校园通知、余额、开放时间等部分内容为代码内样本，不是学校实时数据。
- 可选配置 `POSTGRES_URL` 以使用 PostgreSQL；该路径和公网部署未在本次交付中完成端到端验证。Redis 非本机基础体验必需。
- 校园帖子、公开内容、站内消息和模型调用涉及个人信息；正式开放给他人前，应由部署方完成账号、数据备份、权限、内容治理和真实学校资料的审核。
